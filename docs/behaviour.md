# How Octaline behaves

Octaline is an original plugin modelled on the behaviour of an eight-band
hardware delay. This page records how each control works and which choices
were made where the hardware's manual does not say.

## Signal flow

* The plugin input is summed to mono and scaled by **Effect** before it
  enters the bands. **Direct** and **Direct Pan** set the dry signal, which
  keeps its stereo image. **Output** scales everything and is not stored in
  presets, like the hardware's output knob.
* Each band reads either the plugin input (**Input = IN**) or the output of a
  lower-numbered band. A band's output for chaining is its own input plus its
  echoes, so a series chain adds delay to both the dry sound and the earlier
  echoes.
* Every band's echoes are panned with **Pan** and summed to the output.

## One band

* **Time** 0.02 ms to 697 ms (longer in a group). Time changes glide over
  about 60 ms, so automation and knob moves bend pitch instead of clicking.
* **Tempo** replaces the time with a note value at the host tempo.
* **Feedback** 0 to 10, linear: 5 halves each repeat, 10 repeats forever. A
  soft limiter in the loop keeps infinite feedback from running away.
* **Low cut / High cut** are 6 dB/oct filters inside the feedback loop, so each
  repeat is filtered again. 0 is off and 10 is 1 kHz for both. Between those,
  low cut runs from about 21 Hz (0.1) and high cut from about 15.5 kHz (0.1)
  on a log scale. The first echo is filtered too.
* **Tap** reads the output at a percentage of the delay time while the loop
  keeps the full time. At 360 ms and 66.7 %, the first echo comes at 240 ms
  and then every 360 ms.
* **Speed** 0 to 10 is about 0.16 Hz at 1, 1 Hz at 5 and 10 Hz at 10 (0 stops
  the LFO). **Depth** 0 to 10 sweeps the delay time by up to 8 ms, always
  upwards from the set time, so short flanger times never go below zero.
* **Wave**: Sine, Triangle, Saw Up (pitch rises then jumps back), Saw Down.
  Any band can use any wave; the hardware's limit of two wave types at once is
  not copied.
* **Sync** locks this band's LFO rate to another band. Speed then sets the
  phase offset instead: 5.0 is 180 degrees.
* **Level** 0 to 10, linear, 10 = unity. **Phase Rev** flips polarity.
* **On** switches the band off completely (its echoes stop). **Hold** stops new
  input entering the band while what is already in it keeps repeating.

## Groups

**Group** on a band chains it with the following bands up to the chosen one,
for example band 1 "To 4" makes bands 1-4 one long line. The first band (the
head) sets time, filters, feedback, input and tempo for the whole line. Its
maximum time grows with the group: about 1.44 s for two bands and 5.89 s for
all eight. Each member band keeps its own tap, modulation, pan, level, phase
and on/off, so it acts as an extra read head on the long line.

## Things that can be tuned by ear

The manual only fixes a few points (10 = 1 kHz on the filters, 10 = infinite
feedback, 5.0 sync = 180 degrees). The speed and depth curves, the filter
curves between 0.1 and 10, and the level tapers are reasonable guesses. They
live in `src/dsp/Engine.cpp` (`lowCutHz`, `highCutHz`, `lfoHz`, `depthMs`).

## Factory presets

`src/plugin/FactoryPresets.cpp` holds the 87 patches from the hardware's patch
list (the three loop sampling patches are left out). It is generated by
`tools/extract_patch_list.py` from the patch list PDF, which is not part of
this repository.
